CẬP NHẬT GITHUB
1. Giải nén file ZIP.
2. Trong GitHub repository tranxtruong, thay index.html, style.css và script.js.
3. Nếu đã dùng bản V3 và ảnh/nhạc có sẵn thì KHÔNG cần tải lại assets.
4. Nếu chưa có, tải toàn bộ thư mục assets lên GitHub.
5. Commit changes rồi tải mới trang bằng Ctrl+Shift+R hoặc tab ẩn danh.
