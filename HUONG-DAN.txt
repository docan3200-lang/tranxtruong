CẬP NHẬT GITHUB PAGES
1. Giải nén file ZIP (KHÔNG upload nguyên file ZIP).
2. Mở https://github.com/docan3200-lang/tranxtruong
3. Vào Code, cập nhật 3 file index.html, style.css, script.js và toàn bộ assets/.
   Lưu ý: File mới phải nằm ở thư mục gốc repository, KHÔNG thêm một cấp thư mục con.
4. Commit changes.
5. Nếu Pages đang bật nhánh main /(root), KHÔNG cần bật lại.
6. Mở https://docan3200-lang.github.io/tranxtruong/ và Ctrl+Shift+R (máy tính) / mở tab riêng trên iPhone để tránh cache.
