ĐƯA WEBSITE LÊN GITHUB PAGES

1. Giải nén file ZIP trên máy tính.
2. Mở repository GitHub dùng cho thiệp cưới.
3. Chọn Add file > Upload files.
4. Kéo toàn bộ NỘI DUNG đã giải nén vào repository:
   index.html, style.css, script.js, intro.css, intro.js, thư mục assets và .nojekyll.
   index.html phải nằm ngay ngoài cùng repository, không nằm trong thư mục con.
   Không tải nguyên file ZIP lên repository.
5. Chọn Commit changes.
6. Mở Settings > Pages.
   Source: Deploy from a branch.
   Branch: main (hoặc nhánh bạn vừa tải file lên).
   Folder: / (root).
   Chọn Save.
7. Chờ GitHub triển khai xong rồi mở địa chỉ website trong phần Pages.
   Nếu thay bản cũ mà chưa thấy giao diện mới, tải lại trang và xóa bộ nhớ đệm.

NẾU ĐÃ CÓ WEBSITE GITHUB PAGES

Tải đè index.html, style.css, script.js và các file assets trùng tên.
Tải thêm intro.css, intro.js và toàn bộ thư mục assets trong ZIP để mở phong bì hoạt động.
Giữ nguyên thiết lập Pages hiện có nếu đang dùng main / root.
Không xóa các file khác ngoài phạm vi thiệp nếu repository còn mục đích khác.
