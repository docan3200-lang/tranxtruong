CÁCH ĐĂNG LÊN GITHUB
---------------------
1. Giải nén file zip.
2. Vào repository GitHub của bạn.
3. Upload các file sau để ghi đè file cũ:
   - index.html
   - style.css
   - script.js
   - toàn bộ thư mục assets
4. Commit changes.
5. Nếu GitHub Pages đã bật sẵn main /(root), chỉ cần đợi 1-5 phút.
6. Mở lại website để kiểm tra.

LƯU Ý NHẠC TỰ ĐỘNG
------------------
Website sẽ tự thử phát nhạc ngay khi mở.
Một số trình duyệt điện thoại, đặc biệt iPhone/Safari, có thể chặn nhạc tự động có tiếng.
Khi đó khách chỉ cần chạm "MỞ THIỆP" hoặc chạm nút nhạc một lần để phát.
