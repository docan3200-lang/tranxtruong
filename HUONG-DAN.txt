BỘ THIỆP CƯỚI MINH TRƯỜNG x QUẾ TRÂN
====================================

Bộ file này đã có sẵn:
- 2 ảnh cưới bạn gửi
- Nhạc: Lễ Đường (Dreamland Version) - Kai Đinh
- Link Google Form RSVP
- Mã QR RSVP
- Hiệu ứng hoa rơi
- Nút bật/tắt nhạc

CÁCH CẬP NHẬT LÊN GITHUB
------------------------
1. Mở repository GitHub của bạn.
2. Chọn Add file -> Upload files.
3. Tải toàn bộ file trong thư mục này lên, gồm:
   - index.html
   - style.css
   - script.js
   - thư mục assets
4. Nếu GitHub hỏi ghi đè file cũ, chọn Replace / Commit changes.
5. Vào Settings -> Pages.
6. Ở mục Branch, chọn main và /(root), rồi Save.
7. Đợi 1-5 phút rồi mở website.

LƯU Ý VỀ NHẠC TỰ PHÁT
---------------------
Website đã được cài đặt để TỰ THỬ phát nhạc ngay khi mở.
Tuy nhiên một số trình duyệt điện thoại, nhất là iPhone/Safari, có thể chặn nhạc tự động có tiếng.
Khi đó khách chỉ cần chạm một lần vào màn hình là nhạc sẽ phát.
