THIỆP CƯỚI MINH TRƯỜNG & QUẾ TRÂN – PHIÊN BẢN DELUXE
====================================================

ĐÃ TÍCH HỢP:
- Ảnh cưới từ 2 ảnh JPG bạn cung cấp.
- Nhạc nền: Lễ Đường (Dreamland Version) theo MP3 bạn cung cấp.
- Màn hình phong bì mở thiệp; hoa rơi tự động (không phải video).
- Hiệu ứng xuất hiện khi cuộn; nút bật/tắt nhạc; thanh tiến trình cuộn.
- Link Google Forms RSVP và mã QR.
- Bố cục tối ưu cho điện thoại.

CẬP NHẬT LÊN GITHUB PAGES:
1) Giải nén file ZIP mới.
2) Mở GitHub repository 'tranxtruong'.
3) Do repository đã có index.html, style.css, script.js:
   - Cách dễ nhất: mở từng file cũ trên GitHub -> biểu tượng bút chì -> thay bằng
     nội dung file cùng tên từ bản mới -> Commit changes.
   - Để tải assets: vào repository -> Add file -> Upload files và tải toàn bộ
     thư mục assets mới vào đúng đường dẫn assets/.
   - Nếu GitHub báo trùng file trong khi Upload, có thể dùng giao diện chỉnh
     sửa từng file hoặc xóa file cũ rồi upload bản mới.
4) Đảm bảo index.html, style.css, script.js nằm ngay gốc repo; assets ở assets/.
5) GitHub Settings -> Pages -> Source: Deploy from a branch; main; /(root).
6) Sau khi GitHub Pages deploy, làm mới trang. Nếu trình duyệt còn giữ CSS cũ,
   thử tải lại không dùng cache.

NHẠC TỰ PHÁT:
Website sẽ thử phát nhạc ngay khi mở. Tuy nhiên trình duyệt (nhất là
Safari/iPhone) thường chặn autoplay có âm thanh. Nút 'CHẠM ĐỂ MỞ THIỆP'
phát nhạc trong thao tác chạm, ổn định hơn. Không có cách hợp lệ để đảm bảo
âm thanh tự động phát trên tất cả điện thoại mà không cần tương tác.
